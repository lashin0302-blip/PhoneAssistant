# Phone Assistant — Android starter project

Версия: 0.1.0  
Платформа: Android 8.0+ (minSdk 26), compile/target SDK 35  
Язык: Kotlin

## Что реализовано
- Локальный список приложений с ярлыком запуска.
- Статистика времени на переднем плане за последние 7 дней через UsageStatsManager.
- Ручное включение специального доступа Usage Access в настройках Android.
- Предпросмотр JSON-отчёта перед экспортом.
- Экспорт только по явному действию пользователя через системный выбор файла.
- Быстрые переходы к системным настройкам батареи, трафика и приложений.

## Что намеренно не реализовано
- Нет скрытой передачи данных, фоновой телеметрии или удалённого управления.
- Нет чтения SMS, контактов, фотографий, файлов, паролей или содержимого уведомлений.
- Нет прямого чтения точных per-app battery/network totals: обычные сторонние приложения Android не получают полный доступ к этим системным данным.
- Нет автоматического удаления/отключения приложений. Эти действия должны проходить через системные экраны Android и подтверждаться владельцем телефона.
- Приложение пока не подключено к ChatGPT API. JSON-отчёт можно вручную прикрепить в чат для анализа.

## Сборка
1. Установи Android Studio на ПК.
2. Распакуй архив.
3. Открой папку `PhoneAssistant` в Android Studio.
4. Дождись Gradle Sync. Нужны Android SDK 35 и JDK 17.
5. Подключи Android-телефон с включённой USB debugging либо используй эмулятор.
6. Нажми Run.

## Использование
1. Запусти приложение.
2. Нажми «Разрешить статистику использования».
3. В системном списке найди Phone Assistant и включи разрешение Usage Access.
4. Вернись в приложение и нажми «Собрать диагностический отчёт».
5. Проверь предпросмотр.
6. Нажми «Экспортировать отчёт» и выбери место сохранения.
7. Прикрепи JSON-файл к разговору ChatGPT, чтобы получить анализ.

## Приватность
По умолчанию данные остаются на устройстве. Экспорт создаётся только после нажатия пользователем кнопки и выбора места сохранения.


## Сборка без ПК через GitHub Actions
1. Создай пустой репозиторий на GitHub через мобильный браузер.
2. Загрузи в него содержимое этого архива (не сам ZIP-файл).
3. Открой вкладку Actions и разреши запуск workflows, если GitHub попросит.
4. Запусти `Build Phone Assistant APK` через `Run workflow`.
5. После успешной сборки открой запуск workflow и скачай artifact `phone-assistant-debug-apk`.
6. Распакуй artifact и установи `app-debug.apk`, разрешив установку из выбранного браузера/файлового менеджера.

Сборка выполняется на серверах GitHub; все действия по настройке и установке выполняются с телефона.
